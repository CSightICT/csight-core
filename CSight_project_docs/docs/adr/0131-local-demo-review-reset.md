# ADR-0131: 로컬 시연 문의의 보관 후 검토 초기화

- 상태: Accepted
- 날짜: 2026-09-20
- 근거: 사용자가 운영 상태 하단의 초기화 버튼과 분석을 유지한 검토 재시작을 명시 요청했다.

## 결정

ADMIN, local/test 환경, 내부 피드백 활성화 조건을 모두 만족할 때 현재 조직의
SYNTHETIC_DEMO 문의만 초기화한다. 실운영 문의와 다른 조직은 대상이 아니다.
사진, 원문, 분석, 정책 평가, 검토 패킷, 기존 행동 이력을 보존한다.
처리 결정 및 후속 보고서/모의 처리/학습 자산은 demo_review_resets에 원본 JSON으로
동일 트랜잭션 내 먼저 보관한 후 현재 업무 테이블에서 제거한다. 이는 합성 시연에만
허용하는 기존 처리 이력 보존 규칙의 좁은 예외다. 실제 외부 환불을 취소하지 않는다.

미완료 분석/처리 요청이 있으면 거부한다. 최대100건, 짧은 DB 잠금으로 동시 쓰기를
차단하고, 미리보기 지문과 실행 시점의 지문이 다르면409로 재확인을 요구한다.
검토 담당 배정을 해제하고 PENDING으로 돌리며 version을 올려 오래된 창의 결정을 막는다.
잠금은 짧게 전체 관련 테이블에 적용되므로 로컬 시연 전용이며 실서비스에 활성화하지 않는다.

## 화면과 검증

운영 상태 하단에서 대상 건수를 확인한 뒤 실행한다. 성공 후 화면 캐시를 갱신한다.
실운영 전환 준비도와 버전 정보는 접힌 상세로 이동하며 실제 실패는 숨기지 않는다.
실운영 지표는 기존 PILOT_LIVE 기준을 유지한다. 합성 시연을 실제 고객 성과로 표시하지 않는다.

격리 DB에서 보관/초기화, 분석 불변, 재결정, 오래된 지문 거부와 조직 분리를 검증한다.
실제 DB 초기화는 사용자 버튼 실행 시 수행한다. 마이그레이션은 보관 테이블만 생성한다.
보관 기록이 있으면 downgrade를 거부하며, 자동 보관 복원 기능은 제공하지 않는다.
