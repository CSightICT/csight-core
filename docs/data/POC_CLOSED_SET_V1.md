# PoC 닫힌 클래스·데이터 채택 기준 v1·v2

`evaluation/poc_closed_set_v1/registry.json`은 내부 데모에서 사용할 수 있는 이미지 10건을
고정한 승인 원장이다. 이 파일은 이미지 분류 모델이 아니라 **사람이 승인한 Allowlist와 E3
점수 구간을 검증하는 계약**이다.

## 클래스

| 구분 | 코드 | 화면 표기 | 현재 10건 표현 여부 |
|---|---|---|---|
| 상품 | `PERSONAL_CARE_CONTAINER` | 뷰티·개인관리 용기 | 표현됨 |
| 상품 | `FOOD_OR_SUPPLEMENT_CONTAINER` | 식품·건강보조제 용기 | 미표현 |
| 상품 | `HOUSEHOLD_CHEMICAL_CONTAINER` | 생활화학·접착제 용기 | 미표현 |
| 상품 | `KITCHEN_OR_STORAGE_ITEM` | 주방·수납용 경질 플라스틱 | 표현됨 |
| 결함 | `OPENED_OR_DISASSEMBLED` | 개봉·분해 상태 | 표현됨 |
| 결함 | `SHAPE_OR_STRUCTURAL_DAMAGE` | 변형·파손 | 다중 라벨 1건으로 표현됨 |
| 결함 | `SURFACE_DAMAGE_OR_LEAKAGE` | 표면 손상·누액 | 다중 라벨 1건으로 표현됨 |

현재 사진이 없는 두 상품군을 테스트 완료로 표시하지 않는다. 새 사진은 Qwen 상품 메타데이터
후보를 참고할 수 있지만 사람이 상품군을 승인하고 SHA Allowlist에 추가해야 한다.

## v2 확장 원장

`evaluation/poc_closed_set_v2/registry.json`은 기존 v1 원장을 변경하지 않고 새 이미지 10건을
추가한다. v1과 v2 원장을 함께 적용한 현재 내부 시연 범위는 결함 후보 12건, 사람 확인 저점수
참고 8건으로 총 20건이다. 새 결함 후보에는 식품·건강보조제 1건, 생활화학·접착제 3건,
개인관리 1건, 주방·수납 1건이 포함되어 네 상품군을 모두 표현한다. 이는 클래스별 정확도나
대표 분포 검증이 아니라, 사람이 승인한 닫힌 시연 범위의 표현 여부다.

## 채택 Gate

| 표본 | 필수 조건 |
|---|---|
| 결함 후보 | 승인 상품군, Kaputt 원천 결함 라벨, 지원되는 3개 결함군, E3 `>= 0.95` |
| 저점수 참고 | 사람이 참고 표본으로 승인, 결함군 미지정, E3 `<= 0.10` |
| 회색 구간 | `0.10 < E3 < 0.95`; 선별 데모 제외 또는 담당자 검토 |

E3 운영 임계치 `0.8984375`는 바꾸지 않는다. `0.95`와 `0.10`은 PoC 데이터 선별 여유폭이며
운영 판정 임계치가 아니다. 저점수 참고 표본은 `정상`이 아니고, E3 점수는 결함 종류를
설명하지 않는다.

## 현재 실행 경로

`scripts/seed_realistic_poc_demo.py`로 현실형 v2 데이터를 실행하면 closed-set v1을, 확장 v3를
실행하면 closed-set v2를 기본으로 불러온다. 다음 항목 중 하나라도 다르면 Case 생성 전에 또는
결과 원장 확정 전에 실패한다.

- Dataset·demo ID·상품 참조·source kind·rank·이미지 SHA
- 원천 결함 라벨과 결함군 매핑
- E3 모델 결과의 outcome과 점수 구간
- 사람 승인 플래그와 클래스 계약 버전

시드 결과에는 상품군, 원천 라벨 기반 결함군, 채택 등급을 남긴다. 원본 이미지는 계속 Private
Evidence에만 저장하고, 모델이 결함 유형을 예측했다는 표현이나 정확도·ROI 주장을 만들지 않는다.
