# ADR-0003: LLM이 아닌 정책 엔진과 Human Review가 최종 결정을 소유

- 상태: Accepted
- 일자: 2026-08-25

## Context

LLM은 문의 구조화와 설명에 유용하지만, 환불·교환, 금액, 법적 책임 같은 결정을 자연어 생성 결과에 맡기면 재현성·감사·안전 문제가 발생한다.

## Decision

- LLM은 문의 구조화, 정책 근거 설명, 보고서 생성을 담당한다.
- 정형 정책은 버전 관리된 Policy Evaluator가 실행한다.
- 고위험과 예외 Case는 사람이 검토한다.
- 초기 단계의 모든 최종 결정은 Human Review로 확정한다.

## Consequences

- 규칙과 정책 데이터 설계가 필요하다.
- 모델 변경과 정책 변경의 효과를 분리할 수 있다.
- 기업 감사와 이의제기 대응이 쉬워진다.
