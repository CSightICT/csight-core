# 내부 실모델 피드백 사용 안내

2026-09-10 사용자가 SHADOW 결과의 실제 사용·피드백을 승인한 Mac 전용 구성입니다.

## 사용하는 방법

1. 기존 `CSight 서버 제어.app`에서 서버를 켜고 상담원 화면을 엽니다.
2. 화면을 새로고침해 **실모델 피드백 모드** 안내를 확인합니다.
3. 내부 테스트용 새 문의·사진을 등록하고 분석과 정책 검토를 진행합니다.
4. AI 주장·이미지 판정·정책 인용을 실제 내용과 비교하고 기존 검토 화면에서 담당자가 확인합니다.
   오판·누락·잘못된 인용이 있으면 해당 문의와 분석 버전을 기준으로 피드백합니다.

이전 mock 분석의 재사용은 실모델 검증이 아닙니다. 새 문의로 시작하는 것이 가장 명확합니다.
기존 PRIMARY 분석을 이어서 실모델 검색/설명을 새로 만들면 오류로 안내하며, 새 SHADOW 분석이 필요합니다.
과거 결과와 검토 이력은 삭제하지 않습니다. 별도 자동 학습이나 학습 데이터 승인 기능은 추가하지 않았습니다.

예외: 2026-09-10 사용자가 **모든 테스트 고객사의 기존 115건** 초기화를 별도 승인했습니다.
해당 운영 이력은 복원 검증한 DB 백업으로 보관하고 활성 DB에서 비웠습니다. 기존 사진 bucket은
그대로 보관하며 새 versioned bucket으로 전환했습니다. 일반 사용 중 이력 삭제를 허용한 것은 아닙니다.
[백업·초기화·재적재 기록](TEST_DATA_RESET_2026-09-10.md).

## 실제 연결

| 역할 | 연결 | 범위 |
|---|---|---|
| 문의 구조화·정책 인용 설명 | GX10 Qwen3.8-27B Q5 / llama.cpp | Extraction `2.0.0-local.8`, Grounding `1.1.0-local.2` |
| 이미지 분석 | Mac E3 / MPS | 이미지 전체의 이상 점수만 제공; 위치·결함 종류·정상 확정 아님 |
| 정책 검색 | Qwen3 Embedding + 기존 정책 인덱스 | RAW → HYBRID → Top 3 |
| 최종 확인 | 인증된 담당자 | AI가 최종 결정하지 않음 |
| 환불·발송 등 | DRY_RUN | 실제 결제·환불·고객 알림 없음 |

LLM Query Builder와 Reranker는 기본 경로에 추가하지 않았습니다.
E3 사용권과 현재 검증 범위 때문에 내부 비상업 테스트 자료로만 사용합니다.
기존 공개 주소에서도 같은 인증된 콘솔을 볼 수 있으므로 `local`이 외부 접근 불가를 뜻하지는 않습니다.

## 기록과 안전 경계

- 상담원의 실제 사용을 막던 SHADOW→정책/검토 금지는 이 프로필에서 해제했습니다.
- 서버가 새 정책 실행에 `shadow_feedback_allowed=true`를 기록합니다. 클라이언트가 지정할 수 없으며
  이후 변경할 수 없습니다. 허용 표시가 없는 Shadow는 계속 데이터베이스에서 차단됩니다.
- 분석 모드는 SHADOW 그대로이고 후보 모델의 미자격·출시 금지 상태는 바뀌지 않았습니다.
- 사용 피드백이 발생한 건은 ‘업무 영향이 전혀 없는 Shadow100 품질 검증’에 포함할 수 없습니다.
- 사람 인증·고객사 격리·최종 확인·원문 보존 정책·모의 실행 경계를 유지합니다.
- 합성 연결 시험과 격리 DB 업무 시험은 고객 정확도나 실제 상담원 확인 완료를 의미하지 않습니다.

## 운영과 되돌리기

로컬 표시 파일 `.csight-internal-feedback`이 제어 앱에
`infra/compose.internal-feedback.yml`을 선택하도록 합니다. 일반 `make up` 또는 기본 Compose는
다른 프로필이므로 피드백 중에는 제어 앱을 사용합니다. SSH 인증은 기존 키만 사용합니다.
API key는 기존 GX10 owner-only 파일에서 암호화된 SSH로 읽고 자식 프로세스 환경에만 전달합니다.
Docker 관리자에게 보이는 런타임 secret과 같은 취급이며 값은 보고서·로그에 기록하지 않습니다.

새 피드백 접수를 끄려면 운영자가 표시 파일을 보존용 이름으로 옮긴 뒤 기본 프로필로 **코드 반영 후 켜기**를
실행합니다. 기존 피드백 검토 건은 이력을 유지하고 사람이 마무리할 수 있습니다.
Migration 0037은 피드백 이력이 하나라도 있으면 downgrade를 거부합니다. 기록을 삭제해서 되돌리지 않습니다.
DB 변경 전 백업: `/private/tmp/csight-feedback-backup-j1ZTjz/core-before-feedback.dump` (owner-only).
이는 임시 로컬 백업이며 장기 백업/복구 훈련 완료를 뜻하지 않습니다.
