체크포인트 forward는 실행했지만 dataset-level 성능 수치는 재평가하지 않았습니다.

E3는 위치나 유형을 찾는 Detection 모델이 아니라 image-level binary any-defect candidate입니다. 보고서의 dataset-level 수치를 개별 이미지 결과에 복사하지 않습니다. Top-100 실제 재생은 checkpoint 연결을 검증했지만 positive-only·correct-only 선택 편향 때문에 AP·AUROC를 재현한 평가가 아닙니다.

Safe Interpretation

0.8984375를 읽는 법

점수 ≥ 0.8984375

  • 고신뢰 결함 후보로 우선 표시
  • 사람이 사진·고객 설명·정책 근거를 함께 검토
  • 결함 유형·위치와 최종 처리는 별도 판단

점수 < 0.8984375

  • 정상이라는 뜻이 아님
  • 결함이 없다는 뜻이 아님
  • 고신뢰 후보 기준 미만으로 남기고 사람 검토
점수 어느 쪽도 자동 승인·거절을 만들지 않습니다. 수동 펌프의 작동 이상은 정지 이미지로 확정하지 않고 영상, 수동 시험 또는 사람 검토가 필요합니다.
