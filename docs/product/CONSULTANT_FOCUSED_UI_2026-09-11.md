# 상담원 중심 UI 개선 — 2026-09-11

멘토링 지적에 따라 첫 화면의 목적을 ‘분석 정보 열람’에서 ‘어떤 문의인지 확인하고 결정’으로 바꾼다.

## 반영 사항

- 문의/검토 목록: 상품명·SKU·가격 대신 문의 앞부분(최대 160자)을 표시한다. 모델 요약이 아닌 원문 미리보기이며, 없으면 환불·교환 등 요청 유형을 표시한다. 상태·대기시간은 남기고 담당자 정보는 관리자에게만 보인다.
- 검토가 준비된 문의: 목록 → 검토로 바로 이동한다. 준비 전 문의는 기존 처리 화면을 사용한다.
- 검토 기본 화면: 사진, 사진 아래 작은 상품명·상품코드·결제 금액, 문의 요약, 숫자 threshold, 허용/비허용.
- 원문·정책 근거·분석 자격·기술 기록은 접어서 제공한다. 요약이 없으면 원문이 처음부터 열린다. 정책 유사도 6개는 상세 안에서 추가로 펼친다.
- 사진 파일 크기·해상도·내부 전송 설명은 검토 첫 화면에서 제외한다. 원본 확대와 실패 시 재시도는 유지한다.
- 보관기간 만료/삭제된 문의 미리보기는 제공하지 않는다. 목록당 SQL 1회이며 별도 모델/API 호출을 추가하지 않는다.

## 숫자와 선택의 의미

현재 크게 표시하는 threshold 70%는 기존 빠른 검토 **준비도 기준**이다. 문의마다 바뀌는 실제 준비도는 별도 작은 숫자다. E3 결함 점수/임계치나 정책 유사도, 모델 정확도를 이 숫자로 합치지 않는다. 기준 자체는 변경하지 않았다.

허용/비허용은 상담원의 선택이다. 정확한 처리 유형·근거·사진을 확인창에서 확인하고 한 번 더 확정한다. 사진 오류, 권한 제한, 근거 부족은 기존처럼 차단한다. 금액이 없으면 만들어내지 않고 ‘금액 정보 없음’으로 표시한다.

## CSight를 사용할 이유와 확인할 효과

목표는 상담원이 여러 화면에서 사진·문의·정책을 찾아 모으고 처리 기록을 작성하는 수고를 줄이는 것이다. 이번 변경은 검토 준비 건의 중간 화면을 생략하고, 기본 화면에서 읽어야 하는 정책·분석 세부 항목을 줄인다. 확정 후 근거가 연결된 기존 보고서 생성 흐름은 그대로 사용한다.

‘기존 방식보다 빠르다’는 아직 측정하지 않았다. 같은 사례와 정책을 사용한 기존 처리/CSight 비교에서 다음을 측정해야 한다.

| 확인할 것 | 측정 방식 |
|---|---|
| 상담 시간 | 문의 열기 → 결정 기록까지의 중앙값·상위 90% 시간, 분석 대기 포함/제외를 각각 기록 |
| 읽기/탐색 부담 | 화면 이동, 상세 펼침, 원문 재확인 횟수 |
| 판단 품질 | 독립 정답 대비 결정 오류, 추가 자료 누락, 잘못된 확정 |
| 기록 부담 | 결정 후 보고서/응답 초안 검토·수정 시간 |

상담원별 사례 순서를 교차 배정하고 단순/예외 문의를 나눠 비교한다. 시간 감소와 동시에 결정 품질이 유지돼야 개선으로 판단한다. 현재 실제 상담원 평가와 시간 절감률은 NOT_RUN.

검증 결과와 미해결 항목은 [현재 상태](../progress/CURRENT_STATUS.md)의 2026-09-11 UI 세션을 참조한다.
브라우저 캡처는 합성 API fixture이며 사진 영역도 테스트 이미지다. 실모델 품질이나 실고객 화면 검증으로 간주하지 않는다.


## 10:25 추가 피드백 반영

사진 아래 상품 캡션도 상품·주문 정보 폴드로 옮겼다. 고객정보·상품/주문정보·원문·정책 근거는
사진/요약/허용·비허용 영역 아래에서 필요할 때만 펼친다. 기존 문의 상세 URL로 들어와도
검토가 준비된 미결정 문의는 결정 화면으로 바로 이동한다. 처리단계 확인 링크는
`?details=1`로 기존 분석/복구 화면을 열며, 그 화면에서도 고객/상품/고정 정책 근거는 접혀 있다.
프런트92·E2E15·타입/lint/build PASS, 로컬Web 반영. 실제 시간절감 측정은 여전히 NOT_RUN.


## 10:39 사진 우선 배치

이상가능성 점수 아래 게이지를 제거했다. 기존 문의 상세도 사진 → 저장된 문의 요약 순서로
표시하며, 요약이 없는 경우 원문임을 명시한다. 요약이 있으면 원문은 접기 메뉴로 제공한다.
지금할일 안내는 오른쪽에 배치한다. 사진 원본 보기와 수치·임계치의 의미는 유지한다.
