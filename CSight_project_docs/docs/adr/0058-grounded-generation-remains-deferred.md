# ADR-0058: Grounded generation remains deferred to Sprint 4C-3

- Status: Accepted
- Date: 2026-08-27

## Decision

Sprint 4C-2 ends at query planning, retrieval, fusion, and stored provenance. It returns no policy
explanation, approval, rejection, responsibility, fraud finding, or final decision.

## Consequences

Citation packs, citation validation, unsupported-claim detection, and grounded evaluation are 4C-3
entry gates.
