# Slice Analysis

The sealed dataset covers single/multiple defects, explicit/no request, evidence requirements,
parent exceptions, escalation, version resolution, hard negatives, long messages, colloquial typos,
ambiguous location, multiple requests, prompt injection, and cross-tenant attempts.

All 120 references resolved to active, effective, same-tenant clauses. Direct deterministic output
had zero empty queries, duplicates, forbidden fields, unknown enums, tenant fields, prompt-injection
violations, and reasoning leakage. RAW remained stronger on aggregate Dev ranking, so no generated
strategy was selected.
